# T3 Company OS Design System

# Design Philosophy

T3 Company OS는

예쁜 화면보다

오래 사용해도 피곤하지 않은 화면을 만든다.

디자인보다

업무가 먼저 보인다.

정보보다

행동이 먼저 보인다.
