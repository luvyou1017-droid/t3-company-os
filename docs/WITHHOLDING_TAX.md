# 프리랜서 원천세 리스트 MVP

## 계산

부가세 포함 정산금을 `Math.round(grossSettlementAmount / 1.1)`로 계산한 값을 원천징수 기준금액으로 사용한다.

- 소득세: 기준금액 × 3%를 계산하고 소수점을 제거한 뒤 `truncateToTenWon`으로 10원 미만 절사
- 지방소득세: 기준금액 × 0.3%를 별도로 계산하고 소수점을 제거한 뒤 `truncateToTenWon`으로 10원 미만 절사
- 총 원천징수액: 위 두 세액의 합
- 최종 지급액: 기준금액 - 소득세 - 지방소득세 - 셀러 또는 매니저 차감

3%와 0.3%를 합쳐 한 번에 계산하지 않으며, 두 세액을 먼저 합산한 뒤 절사하지도 않는다.

### 533,120원 검증 사례

- 기준금액: `Math.round(533,120 / 1.1) = 484,655원`
- 소득세: `484,655 × 3% = 14,539.65원 → 14,530원`
- 지방소득세: `484,655 × 0.3% = 1,453.965원 → 1,450원`
- 총 원천세: `14,530 + 1,450 = 15,980원`
- 최종 지급액: `484,655 - 15,980 = 468,675원`

## 자동 생성과 업데이트

개인 프리랜서이고 계산 완료 및 정산 확정 상태이면 지급 준비 시 원천세 항목을 upsert한다. 정산금, 차감액, 정산 버전, 지급월·지급일 또는 지급요청 상태가 바뀌면 갱신한다.

중복 기준은 `settlementId + ownerType + ownerId + sourceVersion`이다. 업로드·신고·납부 이후 원본 정산 버전이 바뀌면 기존 항목을 `revision_required`로 표시하고 새 버전 항목을 만든다.

## 화면과 내보내기

지급 메뉴의 원천세 리스트에서 KPI, 월·구분·상태 필터, 세액과 최종 지급액, 수동 업로드·신고·납부 상태를 관리한다. CSV용 객체 배열과 클립보드 복사를 제공하며 다운로드는 placeholder다.

## 실제 신고 전 확인

현재 데이터는 홈택스 업로드 형식이나 실제 신고 기능이 아니다. 회사가 사용하는 홈택스 템플릿, 귀속·지급월 규칙, 신고 기한, 지급일, 수정 신고, 세무대리인 검토, 접근 권한과 개인정보 정책을 확정한 뒤 전용 adapter를 연결해야 한다.
